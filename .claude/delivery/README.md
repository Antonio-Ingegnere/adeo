# Historical delivery state

This directory is historical. New delivery uses frozen Switchyard V2 with ignored
`.switchyard/work/<work-id>` and an external persistent QA workspace in Adeo data.
Existing records and metrics are not rewritten or converted. Active legacy work
requires explicit review/archive; there is no cross-engine resume or acceptance.

See [migration and recovery](../../docs/agent/switchyard-delivery.md).
