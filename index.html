Text search

Matches task text, details and tags. Every word has to appear, in any order.

Need to be more specific?

Switch to Query for a filter language that can search by list, tag, priority, due date, repeat and completion — and combine those with AND, OR and NOT.

tag:errands AND due<=today

NOT (list:Home OR done:true)

Query syntax

text, details: ~ !=
list, tag: ~ != · none, any
prioritynone / low / medium / high
donetrue / false
due: != < <= > >= · date, today, tomorrow, yesterday
repeatnone / any / daily / weekly / monthly / yearly

A term is field:value. : is exact, ~ is contains. Combine with AND, OR, NOT and parentheses; bare words search text. Quote names with spaces or symbols: list:"Foo list 1".

Examples

tag:errands AND due<=today

priority:high OR priority:medium

NOT (list:Home OR done:true)

milk due:none #errands
